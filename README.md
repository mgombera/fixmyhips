# fixmyhips.com

A personal companion for patients scheduled for hip arthroscopy with Dr. Mufaddal M. Gombera: what to do today, from booking through one year of recovery.

- Spec: [docs/scope.md](docs/scope.md)
- Source documents: [docs/source](docs/source)
- Stack: Next.js (App Router), TypeScript, Tailwind CSS, Vitest; hosted on Vercel

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm test
npm run build
```
